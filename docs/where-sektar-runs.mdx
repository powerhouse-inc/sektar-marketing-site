# Where Sektar runs

You can run Sektar in three ways. They differ in who keeps it running and where your documents are.

Sektar Cloud and Self-hosted Sektar are the same software. The only difference is who runs it: we do, or you do. The Sektar Desktop App is built differently: it keeps everything on your computer, and you use it on that computer.

Each one is a separate Sektar. Documents don't sync between them.

|  | Sektar Desktop App [Download](/download) | Sektar Cloud [Open my Sektar](/login?want=vetra) | Self-hosted Sektar [Set it up](#self-hosted-sektar) |
| --- | --- | --- | --- |
| What it is | An app you install on your computer | Your own Sektar, hosted for you on Vetra | Sektar in containers, on a server you run |
| How you start | Download the installer for macOS (Apple silicon), Windows or Linux (.deb) | Sign in with Renown and enter an invite code | Build the image from the [source code](https://github.com/powerhouse-inc/sektar) and start it with Docker Compose |
| Without internet | Your documents stay available. Connected accounts wait until you're back online | Not available | You can't sign in |

Connected accounts on Sektar Cloud aren't fully working yet: a new environment can sign in to Google and read from it, but can't save what it reads.

The downloaded Desktop App doesn't include Sektar's Google sign-in yet, so it can't connect Gmail or Google Calendar.

Google hasn't verified Sektar's app yet, so only accounts on our test list can connect Gmail or Google Calendar.

To try Sektar first, use the free option on the [home page](/#start). It runs in a browser tab and keeps your documents in that browser.
